# Pendientes del MVP — Los Olivos Conectados

Este registro distingue problemas de interfaz, funciones descritas y decisiones que aún requieren definición. **Ya funcionan** `GET /catalogos`, registro, login para los cuatro roles, `GET` y `PATCH /usuarios/perfil`, `POST /usuarios/autoridad` exclusivo del Administrador, `GET /reportes/mios`, `GET /reportes/:id`, `GET /reportes/:id/estado`, `GET /reportes/:id/audio`, `GET /alertas`, `GET /notificaciones/mias`, las variantes JSON escrita y multipart de audio de `POST /reportes`, y `POST /reportes/:id/evidencias` y su descarga protegida para fotos/videos. El procedimiento privado del primer Administrador está preparado y probado en una base temporal, pero no ejecutado en la base principal. El frontend distingue el espacio vecinal, la página inicial de Autoridad y la administración mínima. Las carpetas preparadas o las rutas escritas en el contrato no equivalen a código implementado.

| Completar reportes de incidentes | El backend y la pantalla crean reportes normales con JSON escrito o multipart de audio. Ya funcionan el detalle privado del autor, el historial real, la reproducción protegida del audio y la consulta y adición posterior de fotos/video. Una carga fallida puede reintentarse en la sesión abierta; tras recargar, el autor puede volver a elegir el archivo y subirlo al mismo reporte. No se conservan archivos locales al recargar.
